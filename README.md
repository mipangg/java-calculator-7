# 문자열 덧셈 계산기

## 기능 구현 목록

### 계산기
[x] 입력한 문자열에서 숫자를 추출하여 더할 수 있다.   
[x] 입력된 숫자는 모두 양수여야 한다.   
[x] 쉼표(,) 또는 콜론(:)을 기준으로 분리한 각 숫자의 합을 반환할 수 있다.   
[x] 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 지정하여 사용할 수 있다.   
[x] 커스텀 구분자는 여러 개 지정할 수 있다.    
[x] 문자열에 공백이 포함될 수 있다.   
[x] 사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료된다.


### 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.

결과 : 0
```
```
덧셈할 문자열을 입력해 주세요.
//k\n
결과 : 0
```
```
덧셈할 문자열을 입력해 주세요.
1,2
결과 : 3
```
```
덧셈할 문자열을 입력해 주세요.
1, 2
결과 : 3
```
```
덧셈할 문자열을 입력해 주세요.
1,2,3
결과 : 6
```
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
```
덧셈할 문자열을 입력해 주세요.
//;\n1;2;3
결과 : 6
```
```
덧셈할 문자열을 입력해 주세요.
//;\n//k\n//.\n1;2k3.4
결과 : 10
```
```
덧셈할 문자열을 입력해 주세요.
//\n1:2
결과 : 3
```
```
덧셈할 문자열을 입력해 주세요.
//kr\n1:2
`IllegalArgumentException` 발생
```
```
덧셈할 문자열을 입력해 주세요.
//k\1:2
`IllegalArgumentException` 발생
```
```
덧셈할 문자열을 입력해 주세요.
//kn1:2
`IllegalArgumentException` 발생
```
